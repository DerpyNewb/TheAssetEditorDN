Kitbash Tools

This page covers the tools that fix and finish a kitbashed model: checking it, rigging it, mirroring, moving and cleaning up meshes, and saving. Every tool is on the Tools menu, and most also have a button on the icon bar. The mesh tools show on the bar in object mode, once a mesh is selected.

Every tool on this page is a single undo step. Press Ctrl+Z once to take back the whole change.

Check model and the save check

Saving checks the model before anything is written. If it finds problems, a window lists them, with a button beside each problem that has a quick fix. Fix what you want, then choose Save anyway or Cancel. Check model on the icon bar runs the same checks without saving, in a window that can stay open while you work. Its list updates after every edit and undo, so a fixed problem drops off on its own.

ProblemWhat it meansHow to fix it
Vertices with no bone weights Those vertices don't follow any bone, so they stay frozen while the unit moves. Bind to one bone... opens the Pin Tool in Bone mode with the mesh listed. For a mesh that should bend, use Skin Wrap or the re-rigging tool instead.
Weights that don't add up to 1 The vertex follows its bones by too much or too little, so it drifts when the unit moves. Normalise weights scales them so they add up to 1, touching only the vertices the check flagged. It's one undo step.
A texture that isn't in any loaded pack The game can't find the file, so that part draws without it. Replace path... opens Replace in texture paths with the path already filled in. You can also add the texture to your pack instead.
A base colour with no sRGB flag The game reads the colours as linear and draws them lighter, often pink or washed out. Open the texture, use Replace from image and pick an _SRGB format such as BC7_UNORM_SRGB.

During a save, Bind to one bone... and Replace path... cancel the save, because they open another tool. Save again when you're done.

Rigging tools

Pin Tool

The Pin Tool makes meshes follow the skeleton. Its Bone mode weights every vertex of the listed meshes fully to one bone, which you pick from a list you can filter. Use it for a rigid part such as a helmet, a shield or a weapon. The Pin Tool page covers its other modes.

If a mesh has a pivot, Apply bakes it into the mesh first, so the mesh stays where it is, and tells you which meshes it baked. The bake and the pin are a single undo step.

Picking a bone in the 3D view

The bone button on the left sidebar, under the Object, Face and Vertex mode buttons, turns on bone picking. While it's on, a click picks the bone nearest the cursor instead of selecting a mesh. The picked bone turns red, and the Pin Tool's Bone mode, the Snap window and the Skeleton panel all select it, so you don't have to find it in a list. A drag still selects meshes. Click the button again to turn picking off. The skeleton has to be visible to pick from it.

Weight view

In the Skeleton panel, turn on Show the selected bone's weights and pick a bone. The model then shows how strongly that bone moves each vertex, from blue (not at all) through green to red (fully). A static mesh that follows a bone without weights shows as blue here, even though it moves.

Re-rigging tool

A mesh taken from a model with a different skeleton names bones this skeleton doesn't have. The re-rigging tool maps each of them to a bone of the target skeleton. The window lists the bones your meshes use that have no target yet, and OK stays disabled until each one is mapped. Clicking a target bone that's already selected maps the next bone to it, so you can send both eyes to head without clicking anything in between. All the selected meshes must use the same skeleton.

Shaping tools

Mirror left to right

This mirrors the selected meshes across the model's centre. Each weight moves to the matching bone on the other side, so a vertex on hand_left moves to hand_right. Use it to make a right shoulder plate from a left one. Mirror left to right, keep bones mirrors the shape but leaves the weights where they are.

Snap to bone or vertex

This moves the selection onto a bone, or onto the centre of vertices you picked in vertex mode. Bones are read in their rest pose, even while an animation plays. Snap only moves the selection; it doesn't rotate it. The same window turns on the rotate gizmo's snapping, with its step in degrees.

Bake pivot

Some meshes carry a pivot, an offset that's applied on top of their vertices. Bake pivot moves the pivot into the vertices and sets it to 0, 0, 0, so the mesh stays where it is. The Pin Tool and Skin Wrap bake a pivot themselves when you apply them.

Recalculate normals and Flip faces

Recalculate normals rebuilds the shading of the selected meshes from their faces. Use it after reshaping a mesh, when its lighting looks wrong. UV seams don't show in the shading, and edges sharper than 60 degrees stay hard.

Flip faces turns a mesh's faces the other way round. Use it on a mesh that shows its inside.

Texture paths

Replace in texture paths finds and replaces text in the texture paths of every mesh, or of the selected meshes only. It shows how many paths will change before you apply, and warns about new paths that aren't in any loaded pack. The window can stay open while you work, and its count follows your selection and your undos. A common use is moving every texture to your own folder after copying the files there.

The save dialog

SettingWhat it does
PathWhere the model is saved, inside your editable pack. Use your own folder and file name unless you mean to replace CA's file for every unit that uses it.
Mesh FormatThe .rigid_model_v2 version. Leave it at the default for WH3.
WS model FormatWrites a .wsmodel next to the model. Pick Warhammer3; the .wsmodel is what gives the model WH3's materials, including faction colours.
Lod StrategyHow the lower-detail versions are made. The default keeps UV seams, open edges and weights. No Lod generation leaves them as they are, which is useful when you only changed textures.
Only save visible nodesLeaves out hidden meshes, so you can keep an old part hidden in the scene without saving it.

The dialog remembers your choices for each game. The path and the LOD settings come from each model.
