SuperView and Meta Editing

An animation's meta file (.anm.meta, or .snd.meta for sounds) holds tags: timed events and settings that ride on the animation. A tag can fire a projectile, play a sound, show an effect, put a weapon in a hand or hide the model. SuperView plays a unit's animation with its tags drawn on it, and the meta editor beside it is where you change them.

Opening a unit in SuperView

  1. Open the unit's variant mesh definition from the pack explorer and pick SuperView when AssetEditor asks which editor to use. The battle table grid's Preview button opens SuperView too.
  2. Pick the unit's animation set in Fragment, then an animation in Slot. The model plays it, and the meta editor loads that slot's meta file.

The meta editor has two tabs. Animation holds the tags of the slot you picked. Persistent holds the tags of the set's persistent meta, which apply whatever the unit is doing, such as a prop it always carries or an effect that never stops.

Reading the viewport

Tags with a position are drawn as markers with a label. A marker is black, and red while its tag is selected in the meta editor.

Event tags also show when they fire. These are FIRE_POS (where the projectile spawns), IMPACT_POS (the hit), TARGET_POS, CAMERA_SHAKE_POS, SOUND_TRIGGER and SPLASH_ATTACK. The label carries the time, such as FirePos @1.13s, and an orange ring lights round the marker for a quarter of a second from that time. A tag with a longer window, such as SplashAttack 0.20-1.00s, stays lit for the whole window. Almost every vanilla event tag is an instant, so most light up for only that quarter of a second.

The tag timeline

The Tag timeline strip, above the Persistent and Animation tabs, shows every tag with a time at once. Each tag is a tick at its start time, and a tag whose end time is later gets a bar running to its end. Hover a tick to see the tag and its time. Click it to move the animation to that moment, paused, and select the tag in the editor. The selected tag's tick is red. A tag that starts before the clip or after its end is drawn as a dashed tick at the nearer edge.

Timing a tag

To put a tag on a particular frame, step or scrub the animation to it, select the tag, and click Set start to now or Set end to now under the tag list. The time goes into the tag's field, and each click is one undo step. The buttons only show in SuperView, because the meta editor on its own has no animation to read the time from.

Moving a tag in the viewport

Select a tag with a position on the Animation tab, and a handle with red, green and blue arrows appears on its marker. Drag an arrow to move the tag along it. The position fields follow as you drag, and one Ctrl+Z undoes the whole drag. Alt and a drag still turn the camera.

This works for FIRE_POS, IMPACT_POS, TARGET_POS, CAMERA_SHAKE_POS, CREW_LOCATION (its position only; its facing is still typed in) and both ends of SPLASH_ATTACK. It also works for SOUND_TRIGGER and EFFECT, whose positions are measured from a bone: the handle stands where the marker is at the current moment, and the tag stores the position relative to its bone. Tags on the Persistent tab get no handle.

Show VFX turns the effects' particles on and off. VFX filter picks which unit's effects play: a unit and its Regiment of Renown often share one meta file, with a different id on each effect.

What SuperView draws

SuperView draws the tags that change what you see: props and animated props, effects and blood, the event markers above, splash attack areas, crew positions, weapons moved between hands and hips, hand and face poses, and the tags that hide, fade or rescale the model. Many other tags change how the game uses the animation rather than how it looks, and those are edited blind: nothing in the viewport changes when you edit them.

An eye beside each tag in the tag list says which kind it is, and the New tag window has the same mark in its SuperView column. An open eye means SuperView draws the tag. An outlined eye means it draws part of it, and the tooltip says which part is missing. A faint crossed-out eye means SuperView doesn't draw it at all.

Editing tags

  • New adds a tag. The Vanilla WH3 uses column says how often CA's own files use each tag version. Pick a version with uses; versions with none are dimmed, and many of them come from other games and don't take effect in WH3.
  • Select a tag to see its fields. Hover a field for what it means.
  • Copy and Paste copy tags from one file to another, and Up and Down reorder them. Every change can be undone.
Copy CA's values. A new tag starts with placeholder values. Start from how the game's own animations use the tag instead, with the vanilla examples below.

Vanilla examples

When you pick a tag in the New tag window, the panel under the list shows up to five of the game's own animations that use it. Files that use the tag in different ways come first. Pick one to see its values, then click Insert like this one to add the new tag with those values instead of the placeholders.

Vanilla examples under the tag list opens the same list for the selected tag, in a window that follows your selection. Copy into selected tag replaces the selected tag's values with the example's, as one undo step.

The examples are read from the game's packs the first time you ask, which takes a few seconds. After that they show at once. With no game packs loaded, there are no examples to show.

Check meta

Check meta lists problems in the open meta file. Click a problem to select its tag, and use Check again after fixing it. It looks for:

  • a tag whose end time is before its start time;
  • a tag that starts after the animation ends;
  • a tag version the game's own files never use, with the version they use most;
  • a weapon bone number that names no be_prop bone on the skeleton, whichever way the game counts;
  • an effect whose file isn't in any loaded pack, and an effect with no file named at all.

Some checks need to know the animation and its skeleton, so they only run in SuperView. The window lists any check it couldn't run.

Saving

Save writes over the meta file you opened. Many animation sets can name the same file, so a change there reaches every one of them. Save meta as... and assign to slot saves a new file in your editable pack instead, points this slot at it and leaves the original alone. Slot files lets you point the slot at a different animation, meta or sound file.

Saving doesn't damage what it can't read. A tag the editor can't decode is shown in red and written back unchanged.

Things that catch people out

  • The animation set decides which weapons show. Each slot of a WH3 animation set carries a weapon flag per be_prop bone, and the game hides the weapons whose flag is off. Edit those in the animation set.
  • Weapon bone numbers. The docking and weapon tags name a weapon bone by number. SuperView reads number n as be_prop_(n-1). Whether the game counts the same way hasn't been confirmed, so check a docking change in game.
  • Docking needs the animation set. A tag that moves a weapon to a hand uses the set's DOCK_EQUIPMENT_* animation for where it sits, so pick the set before judging it.
